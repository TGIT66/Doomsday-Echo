## 1. 改造目标

### 1.1 要改的

- **题材**：从《吞噬星空》同人改为**末日丧尸**原创设定，规避同人版权问题。
- **包装**：所有名称、图标、文案、配色调性。
- **玩法重心**：从"点击攒能量"改成"点击开火杀丧尸赚赏金"，并补上原版缺失的**转生层**与**科技树**。

### 1.2 不动的（框架约束）

- 纯前端、零依赖、零构建，双击 `index.html` 能跑。
- 单个 `game.js` 里"顶部配置区 + 逻辑"的组织方式。
- 数值计算模型：`ceil(baseCost × costMult^已拥有)`、复利成本、`rAF` 主循环、`dt` 上限 1 秒。
- 离线收益"冷启动 + 回前台"结算，不做后台常驻。
- localStorage 自动存档 + base64 存档码导入导出。
- PWA 缓存策略，以及"改代码必须 `CACHE` +1、必须记 CHANGELOG"的规矩。

## 3. 核心循环

```
         ┌──────────────────────────────────────────┐
         │  点屏幕开火 → 击杀丧尸 → 得赏金            │
         └───────────────┬──────────────────────────┘
                         │ 花赏金
                         ▼
         ┌──────────────────────────────────────────┐
         │  军火库：买武器 → 单发伤害↑、自动火力↑     │
         └───────────────┬──────────────────────────┘
                         │ 效率指数上升
                         ▼
         ┌──────────────────────────────────────────┐
         │  赏金到 1e6 → 撤退重整（重置）→ 得声望     │
         └───────────────┬──────────────────────────┘
                         │ 花声望
                         ▼
         ┌──────────────────────────────────────────┐
         │  军队：招兵 → 全局倍率↑、离线↑、点伤↑      │
         └───────────────┬──────────────────────────┘
                         │ 长期积累
                         ▼
         ┌──────────────────────────────────────────┐
         │  科技：用蓝图点科技树 → 军火库大幅强化     │
         └───────────────┬──────────────────────────┘
                         └──────► 回到顶部（更快）
```

三层节奏：**分钟级**（军火库）→ **半小时级**（军队/转生）→ **小时级**（科技）。

## 4. 系统一：军火库（点击 + 自动）

### 4.1 双产出模型

每把武器同时提供两种产出，一次购买吃到两份收益：

- **单发伤害**：参与点击结算，`伤害 = (1 + Σ 拥有数 × 单发伤害) × 战术倍率`
- **自动火力**：每秒自动收赏金，`自动 = Σ 拥有数 × 每秒赏金 × 全局倍率 × 军队 × 科技`

这样"买枪"对点击党和挂机党都成立，不需要再拆两套系统。

## 5. 系统二：军队（转生层）

### 5.1 解锁与重置

- **解锁条件**：单局累计赏金 ≥ **1e6**，主界面出现"撤退重整"入口。
- **重置范围**：当前赏金、军火库全部等级、战术装备、离线档位。
- **保留范围**：声望、士兵、科技、（累计总赏金 / 生存等级 / 战报统计）。
- **二次确认**：弹窗列出"将失去什么 / 将得到什么"，需输入或长按确认（防误触）。

### 5.2 声望公式

```
声望 = floor( ( 单局累计赏金 / 1e6 ) ^ 0.5 )
```

| 单局累计 | 声望 |
|---|---|
| 1e6 | 1 |
| 1e8 | 10 |
| 1e10 | 100 |
| 1e12 | 1,000 |
| 1e14 | 10,000 |

平方根曲线保证"每周目收入递减但总量上升"；系数 `1e6` 与解锁门槛一致，全集中在配置区，方便整体缩放。

### 5.3 兵种表（消耗声望，价格逐次 ×1.5）

| 兵种 | 首价 | 效果（每个） | 上限 |
|---|---|---|---|
| 新兵 | 1 | 自动赏金 **+3%** | 无限 |
| 工兵 | 5 | 单发伤害 **+8%** | 无限 |
| 军医 | 10 | 离线效率 **+2%**（100% → 最高 150%） | 25 |
| 军官 | 25 | 离线时长上限 **+1 小时**（6 → 最高 24 小时） | 18 |

### 5.4 军队等级

```
军队等级 = floor( 总兵力 / 10 )
每级：自动赏金 +5%（加法叠加，不与新兵重复计）
```

给"杂兵堆量"一个额外收益，避免玩家只盯一个兵种。

### 5.5 离线收益并入军队

- **v0.4.0**：离线收益维持现状（6 小时起、效率 100%），先不动。
- **v0.5.0**：改为**首次撤退重整后才解锁**，初始 2 小时 / 50% 效率，靠军医、军官往上爬。
  - 理由：让"转生"成为明确的进度门槛，而不是开局就白送。

## 6. 系统三：科技（草案，待定）

这一块还没定，先给出三个候选方向和一个推荐组合，供选择后再细化。

### 6.1 候选方案

| 方案 | 做法 | 优点 | 风险 |
|---|---|---|---|
| A. 科技树（节点） | 三分支节点，逐个点亮，每个节点给固定倍率 | 直观、易做、可视化好 | 容易变成"纯数值列表" |
| B. 研究队列（时间制） | 选课题 → 真实时间/离线时间推进 → 完成 | 与放置节奏契合、有期待感 | 与离线结算耦合，易出 bug |
| C. 模块改装（插槽） | 武器插槽 + 随机词条 | 有 build 乐趣、可反复刷 | 需要随机与重铸系统，工作量大 |

### 6.2 已定：A + C 轻量混合（v0.2 决策）

- **主干**用 A 的科技树，保证有明确的目标线。
- **爽点**用 C 的"插槽"简化版：每把武器 1 个插槽，可装 1 个**固定词条**（非随机），词条由科技树解锁。
- 不做随机、不做重铸，控制复杂度。
- v0.4.0 已按此方案放出三分支锁定态骨架（`TECH_BRANCHES`），等待 v0.6.0 填节点。

### 6.3 资源：蓝图

| 来源 | 数量 | 说明 |
|---|---|---|
| 击杀精英丧尸 | 1 | 每 25 次点击一只 |
| 尸潮事件（每 5 分钟一波） | 波次等级 | 独立于挂机，鼓励回来点两下 |
| 撤退重整 | 声望 × 10% | 保底，避免卡死 |

### 6.4 三分支（每支 6 节点，每节点 ×1.15~×1.25，末尾大节点 ×1.5）

| 分支 | 主题 | 典型效果 |
|---|---|---|
| 火力 | 枪 | 单发伤害倍率、解锁第 8~9 把武器、暴击 |
| 后勤 | 钱 | 自动赏金倍率、离线效率、自动购买 |
| 生物 | 人 | 点击连锁、精英出现率、士兵效果加成 |

### 6.5 预留接口（先留空，v0.6.0 填内容）

```js
var TECH = [];            // 节点配置，空数组即为"未实装"
function techMult(kind) { // kind: 'click' | 'auto'
  return 1;               // 未实装时恒为 1
}
```

在 `getRate()` 与 `getClickPower()` 里预留乘位，后续接入不用改主循环。

## 7. 数值框架

### 7.1 公式（与现版本一致，只换名字与新增乘区）

| 项目 | 公式 |
|---|---|
| 武器成本 | `ceil(baseCost × 1.15^已拥有)` |
| 装备成本 | `ceil(baseCost × costMult^等级)` |
| 单发伤害 | `(1 + Σ 拥有 × 单发伤害 + 穿甲弹×2) × Π(点击倍率) × Π(军队点击) × Π(科技点击)` |
| 自动赏金 | `Σ(拥有 × 每秒赏金) × Π(全局倍率) × Π(军队自动) × Π(科技自动)` |
| 声望 | `floor((单局累计 / 1e6) ^ 0.5)` |
| 离线赏金 | `自动赏金 × min(离开秒数, 上限) × 效率` |

### 7.2 平衡目标（先按这个验收，再微调）

| 节点 | 目标时长 | 判定标准 |
|---|---|---|
| 手枪 → 冲锋枪 | 1~2 分钟 | 首次购买有即时反馈 |
| 解锁撤退重整（1e6） | 12~18 分钟 | 单局第一次有"该转了"的感觉 |
| 首次转生后回到 1e6 | 3~5 分钟 | 倍率要肉眼可见 |
| 单次周目 | 20~30 分钟 | 不拖沓也不空白 |
| 单次声望收益 | 上一个周目的 3~10 倍 | 指数感 |
| 科技第一支点满 | 3~5 小时 | 中期目标 |
| 满科技 + 满军队 | 20 小时+ | 长线 |

### 7.3 不再追求的东西

- 单局内"冲上 1e20"——不可能，也没必要，等级跨周目累积。
- 大数库——转生后倍率叠加前先按 `5 层周目` 估算上限，超 `1e100` 再议。

## 11. 风险

| 风险 | 说明 | 对策 |
|---|---|---|
| 题材自查 | 改为原创末日设定后已脱离《吞噬星空》，仍需避免直接使用知名 IP 的专有名词 | 全部名称自拟，见第 2 章 |

### 12.1 已定（2026-10-29）

| # | 问题 | 决定 |
|---|---|---|
| 1 | 界面形态 | **采用底部 tab**（军火库 / 军队 / 科技 / 战报），已落地 |
